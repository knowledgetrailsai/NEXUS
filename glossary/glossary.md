# Glossary

`Home › Glossary`

| Term | Definition | See |
|---|---|---|
| **Automation Ceiling** | The highest automation level (L1–L4) a use case could plausibly reach with strong evidence and governance | [Agentic Automation Spectrum](../01-foundations/agentic-automation-spectrum.md) |
| **Core / Adaptable / Limited** | Grid cell ratings for how well-evidenced a function's pattern is in a given domain | [Opportunity Grid](../04-grid/opportunity-grid.md) |
| **Domain** | An industry vertical (e.g., Healthcare, Retail & CPG) with its own regulatory and operational context | [03-domains](../03-domains/advertising-media.md) |
| **Function** | A recurring business capability (e.g., Sales, Procurement) whose automation pattern is largely industry-independent | [02-functions](../02-functions/claims-management.md) |
| **Grid** | The function × domain matrix used to organize this repository | [00-navigation-and-methodology/knowledge-map.md](../00-navigation-and-methodology/knowledge-map.md) |
| **L1 (Assist)** | Human does the work, AI suggests/drafts, human reviews everything | [Agentic Automation Spectrum](../01-foundations/agentic-automation-spectrum.md) |
| **L2 (Automate)** | AI executes one bounded task end-to-end, human reviews samples/exceptions | [Agentic Automation Spectrum](../01-foundations/agentic-automation-spectrum.md) |
| **L3 (Agentic)** | AI plans and executes a multi-step workflow, escalating exceptions | [Agentic Automation Spectrum](../01-foundations/agentic-automation-spectrum.md) |
| **L4 (Autonomous)** | AI operates within policy bounds without per-task approval, monitored continuously | [Agentic Automation Spectrum](../01-foundations/agentic-automation-spectrum.md) |
| **Use Case** | A concrete, function-primary automation opportunity entry with problem, pattern, maturity, value signal, and risks | [05-use-cases](../05-use-cases/benefits-eligibility-document-verification-agent.md) |
| **Value Signal** | A plausible outcome/value hypothesis named in a use case — not a sourced, sign-off-backed value case | [Principles](../01-foundations/principles.md#value-signal-not-a-value-case) |
